# BI for Intune Model Context

> Not released. No model context has been published yet.

Model context describes the BI for Intune semantic model to an AI tool: what the model is for, the terminology it uses, and how its measures and relationships should be used. It lets an AI tool rely on the business logic already in the model instead of guessing.

Table, column, and measure names in this folder will be taken from the released model. Each file will state which model versions it applies to.
