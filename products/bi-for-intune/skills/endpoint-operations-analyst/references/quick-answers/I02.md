# I02: Which app is failing to install on the most devices?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR ByApp =
        SUMMARIZECOLUMNS (
            'Application'[App ID], 'Application'[App Name],
            TREATAS ( { "Failed" }, 'Application State'[App Status] ),
            TREATAS ( Active, 'User Devices'[Intune Device ID] ),
            "N", DISTINCTCOUNT ( 'User Devices'[Intune Device ID] )
        )
    VAR TopApp = TOPN ( 1, ByApp, [N], DESC, 'Application'[App Name], ASC )
    VAR AppId = MAXX ( TopApp, 'Application'[App ID] )
    VAR WithStatus =
        CALCULATE ( DISTINCTCOUNT ( 'User Devices'[Intune Device ID] ),
            'Application'[App ID] = AppId,
            'Application State'[App Status] IN { "Installed", "Not Installed", "Failed", "Install Pending", "Uninstall Failed" },
            TREATAS ( Active, 'User Devices'[Intune Device ID] ) )
EVALUATE
ROW (
    "App", MAXX ( TopApp, 'Application'[App Name] ),
    "Devices", FORMAT ( MAXX ( TopApp, [N] ) + 0, "#,0" ),
    "WithStatus", FORMAT ( WithStatus + 0, "#,0" ),
    "Pct", FORMAT ( DIVIDE ( MAXX ( TopApp, [N] ) + 0, WithStatus ) + 0, "0.0%" ),
    "AsOf", AsOf
)
```

**Answer:** {App} is failing to install on {Devices} managed devices, {Pct} of the {WithStatus} devices that report a status for it. (data as of {AsOf})
