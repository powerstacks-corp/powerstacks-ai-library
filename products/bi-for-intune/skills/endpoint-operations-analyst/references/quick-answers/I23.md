# I23: How many managed devices do we have, by platform?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR M = CALCULATETABLE ( SUMMARIZE ( Device, Device[Intune Device ID], Device[OS] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR P = DISTINCT ( SELECTCOLUMNS ( M, "Id", Device[Intune Device ID],
        "Plat", SWITCH ( TRUE (),
            CONTAINSSTRING ( Device[OS], "Windows" ), "Windows",
            Device[OS] IN { "iOS/iPadOS", "Ios", "iPad", "iPhone" }, "iOS/iPadOS",
            Device[OS] IN { "MacOS", "Osx" }, "macOS",
            CONTAINSSTRING ( Device[OS], "Android" ) || CONTAINSSTRING ( Device[OS], "AOSP" ), "Android",
            "Other" ) ) )
    VAR G = GROUPBY ( P, [Plat], "N", COUNTX ( CURRENTGROUP (), 1 ) )
    VAR Total = COUNTROWS ( Active )
EVALUATE
SELECTCOLUMNS ( G, "Platform", [Plat], "Devices", FORMAT ( [N] + 0, "#,0" ), "Pct", FORMAT ( DIVIDE ( [N] + 0, Total ) + 0, "0.0%" ), "Total", FORMAT ( Total + 0, "#,0" ), "AsOf", AsOf, "SortN", [N] )
ORDER BY [SortN] DESC
```

**Answer:** You have {Total} managed devices, by platform (data as of {AsOf})

**Each row:** {Platform}: {Devices} ({Pct})
