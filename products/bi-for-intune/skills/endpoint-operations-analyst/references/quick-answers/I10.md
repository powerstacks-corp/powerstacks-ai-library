# I10: Which configuration profile has the most errors or conflicts?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR ByCfg =
        SUMMARIZECOLUMNS (
            'Configuration'[Configuration Name],
            TREATAS ( { "Error", "Conflict" }, 'Configuration State'[Configuration Status] ),
            TREATAS ( Active, 'Configuration State'[Intune Device ID] ),
            "N", DISTINCTCOUNT ( 'Configuration State'[Intune Device ID] )
        )
    VAR TopCfg = TOPN ( 1, ByCfg, [N], DESC, 'Configuration'[Configuration Name], ASC )
    VAR Cfg = MAXX ( TopCfg, 'Configuration'[Configuration Name] )
    VAR Applies =
        CALCULATE ( DISTINCTCOUNT ( 'Configuration State'[Intune Device ID] ),
            'Configuration'[Configuration Name] = Cfg,
            'Configuration State'[Configuration Status] IN { "Compliant", "Non Compliant", "Error", "Conflict" },
            TREATAS ( Active, 'Configuration State'[Intune Device ID] ) )
EVALUATE
ROW ( "Profile", Cfg, "Devices", FORMAT ( MAXX ( TopCfg, [N] ) + 0, "#,0" ), "Applies", FORMAT ( Applies + 0, "#,0" ), "Pct", FORMAT ( DIVIDE ( MAXX ( TopCfg, [N] ) + 0, Applies ) + 0, "0.0%" ), "AsOf", AsOf )
```

**Answer:** The configuration profile with the most errors or conflicts is {Profile}: {Devices} managed devices, {Pct} of the {Applies} it reports on. (data as of {AsOf})
