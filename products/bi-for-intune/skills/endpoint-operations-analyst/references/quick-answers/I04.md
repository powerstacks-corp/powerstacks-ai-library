# I04: Which compliance policy has the most non-compliant devices?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR ByPol =
        SUMMARIZECOLUMNS (
            'Compliance Policy'[Policy Name],
            TREATAS ( { "Non Compliant" }, 'Compliance Policy State'[Policy Status] ),
            TREATAS ( Active, 'Compliance Policy State'[Intune Device ID] ),
            "N", DISTINCTCOUNT ( 'Compliance Policy State'[Intune Device ID] )
        )
    VAR TopPol = TOPN ( 1, ByPol, [N], DESC, 'Compliance Policy'[Policy Name], ASC )
    VAR PolName = MAXX ( TopPol, 'Compliance Policy'[Policy Name] )
    VAR Evaluated =
        CALCULATE ( DISTINCTCOUNT ( 'Compliance Policy State'[Intune Device ID] ),
            'Compliance Policy'[Policy Name] = PolName,
            'Compliance Policy State'[Policy Status] IN { "Compliant", "Non Compliant" },
            TREATAS ( Active, 'Compliance Policy State'[Intune Device ID] ) )
EVALUATE
ROW ( "Policy", PolName, "Devices", FORMAT ( MAXX ( TopPol, [N] ) + 0, "#,0" ), "Evaluated", FORMAT ( Evaluated + 0, "#,0" ), "Pct", FORMAT ( DIVIDE ( MAXX ( TopPol, [N] ) + 0, Evaluated ) + 0, "0.0%" ), "AsOf", AsOf )
```

**Answer:** The compliance policy with the most non-compliant devices is {Policy}: {Devices} managed devices, {Pct} of the {Evaluated} it evaluates. (data as of {AsOf})
