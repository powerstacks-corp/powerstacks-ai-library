# I11: Which Windows 11 versions are we running?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR W = CALCULATETABLE ( SUMMARIZE ( Device, Device[Intune Device ID], Device[OS Release ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[OS] = "Windows 11" )
    VAR V = DISTINCT ( SELECTCOLUMNS ( W, "Id", Device[Intune Device ID], "Ver", IF ( ISBLANK ( Device[OS Release ID] ), "Version not reported", SUBSTITUTE ( Device[OS Release ID], "Windows 11, version ", "" ) ) ) )
    VAR G = GROUPBY ( V, [Ver], "N", COUNTX ( CURRENTGROUP (), 1 ) )
    VAR Total = COUNTROWS ( DISTINCT ( SELECTCOLUMNS ( W, "Id", Device[Intune Device ID] ) ) )
    VAR T = TOPN ( 10, G, [N], DESC, [Ver], ASC )
EVALUATE
SELECTCOLUMNS ( T, "Version", [Ver], "Devices", FORMAT ( [N] + 0, "#,0" ), "Pct", FORMAT ( DIVIDE ( [N] + 0, Total ) + 0, "0.0%" ), "Total", FORMAT ( Total + 0, "#,0" ), "AsOf", AsOf, "SortN", [N] )
ORDER BY [SortN] DESC, [Version] ASC
```

**Answer:** {Total} managed devices run Windows 11, by version (data as of {AsOf})

**Each row:** {Version}: {Devices} devices ({Pct})
