# I03: How many Windows devices are missing the latest security update?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR Known = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[OS] IN { "Windows", "Windows 10", "Windows 11", "Windows10" }, Device[OS Security Update Status] IN { "Latest", "Not Latest", "Multiple Security Updates Missing" } )
    VAR Behind = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[OS] IN { "Windows", "Windows 10", "Windows 11", "Windows10" }, Device[OS Security Update Status] IN { "Not Latest", "Multiple Security Updates Missing" } )
    VAR Multi = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[OS] IN { "Windows", "Windows 10", "Windows 11", "Windows10" }, Device[OS Security Update Status] = "Multiple Security Updates Missing" )
EVALUATE
ROW ( "Behind", FORMAT ( Behind + 0, "#,0" ), "Known", FORMAT ( Known + 0, "#,0" ), "Pct", FORMAT ( DIVIDE ( Behind + 0, Known ) + 0, "0.0%" ), "Multiple", FORMAT ( Multi + 0, "#,0" ), "AsOf", AsOf )
```

**Answer:** {Behind} of {Known} managed Windows devices that report update status ({Pct}) are missing the latest security update, and {Multiple} are missing two or more. Source: Windows Update for Business reports. (data as of {AsOf})
