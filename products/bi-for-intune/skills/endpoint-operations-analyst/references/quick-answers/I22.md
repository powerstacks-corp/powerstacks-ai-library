# I22: How many device enrollments failed recently?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR N = DISTINCTCOUNT ( 'Device Enrollment Failure'[Enrollment Failure ID] )
    VAR FromD = MIN ( 'Device Enrollment Failure'[Enrollment Failure Time] )
    VAR ToD = MAX ( 'Device Enrollment Failure'[Enrollment Failure Time] )
    VAR ByCat =
        SUMMARIZECOLUMNS ( 'Device Enrollment Failure'[Failure Category], "C", DISTINCTCOUNT ( 'Device Enrollment Failure'[Enrollment Failure ID] ) )
    VAR TopCat = TOPN ( 1, FILTER ( ByCat, NOT ISBLANK ( 'Device Enrollment Failure'[Failure Category] ) ), [C], DESC, 'Device Enrollment Failure'[Failure Category], ASC )
EVALUATE
ROW ( "Failures", FORMAT ( N + 0, "#,0" ), "From", FORMAT ( FromD, "yyyy-mm-dd" ), "To", FORMAT ( ToD, "yyyy-mm-dd" ),
    "TopCategory", COALESCE ( MAXX ( TopCat, 'Device Enrollment Failure'[Failure Category] ), "not reported" ),
    "TopCount", FORMAT ( COALESCE ( MAXX ( TopCat, [C] ), 0 ), "#,0" ), "AsOf", AsOf )
```

**Answer:** {Failures} device enrollment attempts failed between {From} and {To}. The most common category is {TopCategory} ({TopCount} failures). (data as of {AsOf})
