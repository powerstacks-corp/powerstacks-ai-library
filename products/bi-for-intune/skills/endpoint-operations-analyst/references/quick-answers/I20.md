# I20: What are our top 5 device models?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR G =
        CALCULATETABLE (
            SUMMARIZECOLUMNS ( Device[Device Manufacturer], Device[Device Model], "N", DISTINCTCOUNT ( Device[Intune Device ID] ) ),
            Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, NOT ISBLANK ( Device[Device Model] ) )
    VAR T = TOPN ( 5, G, [N], DESC, Device[Device Model], ASC, Device[Device Manufacturer], ASC )
EVALUATE
SELECTCOLUMNS ( T, "Manufacturer", Device[Device Manufacturer], "Model", Device[Device Model], "Devices", FORMAT ( [N] + 0, "#,0" ), "AsOf", AsOf, "SortN", [N] )
ORDER BY [SortN] DESC, [Model] ASC
```

**Answer:** Your top 5 device models among managed devices (data as of {AsOf})

**Each row:** {Manufacturer} {Model}: {Devices} devices
