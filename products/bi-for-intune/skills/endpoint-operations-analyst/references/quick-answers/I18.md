# I18: Are any connectors or tokens expired?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR C = 'Connector & Token'
    VAR Expired = COUNTROWS ( FILTER ( C, 'Connector & Token'[Is Expired] = TRUE () ) )
    VAR NotOk = COUNTROWS ( FILTER ( C, 'Connector & Token'[Connector State] <> "Success" ) )
    VAR Upcoming = FILTER ( C, NOT ISBLANK ( 'Connector & Token'[Expiration Date] ) && 'Connector & Token'[Expiration Date] >= TODAY () )
    VAR NextRow = TOPN ( 1, Upcoming, 'Connector & Token'[Expiration Date], ASC, 'Connector & Token'[connector.id], ASC )
    VAR NextDate = MAXX ( NextRow, 'Connector & Token'[Expiration Date] )
EVALUATE
ROW ( "Expired", FORMAT ( Expired + 0, "#,0" ), "NotHealthy", FORMAT ( NotOk + 0, "#,0" ), "Total", FORMAT ( COUNTROWS ( C ) + 0, "#,0" ),
    "NextType", COALESCE ( MAXX ( NextRow, 'Connector & Token'[Connector Type] ), "none" ),
    "NextDate", IF ( ISBLANK ( NextDate ), "no date reported", FORMAT ( NextDate, "yyyy-mm-dd" ) ),
    "AsOf", AsOf )
```

**Answer:** {Expired} of {Total} connectors and tokens are expired and {NotHealthy} are not in a healthy state. The next to expire is the {NextType}, on {NextDate}. (data as of {AsOf})
