# I05: When do our Apple certificates and tokens expire?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR A = FILTER ( 'Connector & Token', 'Connector & Token'[Connector Platform] = "Apple" && NOT ISBLANK ( 'Connector & Token'[Expiration Date] ) )
    VAR R =
        ADDCOLUMNS ( A,
            "D", DATEDIFF ( TODAY (), 'Connector & Token'[Expiration Date], DAY ) )
    VAR T = TOPN ( 10, R, 'Connector & Token'[Expiration Date], ASC, 'Connector & Token'[connector.id], ASC )
EVALUATE
SELECTCOLUMNS ( T,
    "Connector", 'Connector & Token'[Connector Type],
    "Expires", FORMAT ( 'Connector & Token'[Expiration Date], "yyyy-mm-dd" ),
    "Status", IF ( [D] < 0, "expired " & FORMAT ( -[D], "#,0" ) & " days ago", "in " & FORMAT ( [D], "#,0" ) & " days" ),
    "Count", FORMAT ( COUNTROWS ( A ), "#,0" ),
    "AsOf", AsOf,
    "SortDate", 'Connector & Token'[Expiration Date] )
ORDER BY [SortDate] ASC
```

**Answer:** Your {Count} Apple certificates and tokens, soonest first, with days counted from today in UTC (data as of {AsOf})

**Each row:** {Connector}: expires {Expires} ({Status})
