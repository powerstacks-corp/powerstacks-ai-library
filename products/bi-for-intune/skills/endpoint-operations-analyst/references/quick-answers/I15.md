# I15: How many Windows 10 devices are still in use?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR W10 = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[OS] IN { "Windows 10", "Windows10" } )
    VAR W10r = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[OS] IN { "Windows 10", "Windows10" }, NOT ISBLANK ( Device[Last Check-In (Days)] ), Device[Last Check-In (Days)] <= 30 )
    VAR Win = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[OS] IN { "Windows", "Windows 10", "Windows 11", "Windows10" } )
EVALUATE
ROW ( "Win10", FORMAT ( W10 + 0, "#,0" ), "Windows", FORMAT ( Win + 0, "#,0" ), "Pct", FORMAT ( DIVIDE ( W10 + 0, Win ) + 0, "0.0%" ), "Recent", FORMAT ( W10r + 0, "#,0" ), "AsOf", AsOf )
```

**Answer:** {Win10} managed devices still run Windows 10 ({Pct} of {Windows} managed Windows devices), and {Recent} of them checked in within the last 30 days. Windows 10 reached end of support on October 14, 2025. (data as of {AsOf})
