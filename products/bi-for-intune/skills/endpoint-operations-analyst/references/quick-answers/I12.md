# I12: How many devices haven't checked in for 30 days?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR Stale = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, NOT ISBLANK ( Device[Last Check-In (Days)] ), Device[Last Check-In (Days)] > 30 )
    VAR Over90 = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, NOT ISBLANK ( Device[Last Check-In (Days)] ), Device[Last Check-In (Days)] > 90 )
    VAR Total = COUNTROWS ( Active )
EVALUATE
ROW ( "Stale", FORMAT ( Stale + 0, "#,0" ), "Total", FORMAT ( Total + 0, "#,0" ), "Pct", FORMAT ( DIVIDE ( Stale + 0, Total ) + 0, "0.0%" ), "Over90", FORMAT ( Over90 + 0, "#,0" ), "AsOf", AsOf )
```

**Answer:** {Stale} of {Total} managed devices ({Pct}) haven't checked in for more than 30 days, and {Over90} of them for more than 90 days. (data as of {AsOf})
