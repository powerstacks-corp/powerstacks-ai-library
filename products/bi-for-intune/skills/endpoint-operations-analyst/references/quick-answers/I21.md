# I21: How many Windows devices have less than 10 GB free?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR Rep = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[OS] IN { "Windows", "Windows 10", "Windows 11", "Windows10" }, NOT ISBLANK ( Device[Total Space (GB)] ), Device[Total Space (GB)] > 0 )
    VAR Low = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[OS] IN { "Windows", "Windows 10", "Windows 11", "Windows10" }, NOT ISBLANK ( Device[Total Space (GB)] ), Device[Total Space (GB)] > 0, NOT ISBLANK ( Device[Free Space (GB)] ), Device[Free Space (GB)] < 10 )
EVALUATE
ROW ( "Low", FORMAT ( Low + 0, "#,0" ), "Reporting", FORMAT ( Rep + 0, "#,0" ), "Pct", FORMAT ( DIVIDE ( Low + 0, Rep ) + 0, "0.0%" ), "AsOf", AsOf )
```

**Answer:** {Low} of {Reporting} managed Windows devices that report storage ({Pct}) have less than 10 GB of free disk space. (data as of {AsOf})
