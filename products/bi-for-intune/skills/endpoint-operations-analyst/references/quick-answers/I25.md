# I25: When was the data last refreshed?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR R = MAX ( 'Authorization'[Refresh Time] )
    VAR L = CALCULATE ( MAX ( Device[Last Check-In] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
EVALUATE
ROW ( "HoursAgo", FORMAT ( DATEDIFF ( R, UTCNOW (), HOUR ), "#,0" ), "LatestCheckIn", FORMAT ( L, "yyyy-mm-dd hh:nn" ) & " UTC", "AsOf", AsOf )
```

**Answer:** The data was last refreshed at {AsOf}, about {HoursAgo} hours ago. The most recent device check-in in it is {LatestCheckIn}. (data as of {AsOf})
