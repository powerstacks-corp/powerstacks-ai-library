# I19: How many devices have a failed app install?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR Hit = CALCULATETABLE ( VALUES ( 'User Devices'[Intune Device ID] ), 'Application State'[App Status] = "Failed", TREATAS ( Active, 'User Devices'[Intune Device ID] ) )
    VAR Apps = CALCULATE ( DISTINCTCOUNT ( 'Application State'[App ID] ), 'Application State'[App Status] = "Failed", TREATAS ( Active, 'User Devices'[Intune Device ID] ) )
    VAR Total = COUNTROWS ( Active )
EVALUATE
ROW ( "Devices", FORMAT ( COUNTROWS ( Hit ) + 0, "#,0" ), "Total", FORMAT ( Total + 0, "#,0" ), "Pct", FORMAT ( DIVIDE ( COUNTROWS ( Hit ) + 0, Total ) + 0, "0.0%" ), "Apps", FORMAT ( Apps + 0, "#,0" ), "AsOf", AsOf )
```

**Answer:** {Devices} of {Total} managed devices ({Pct}) have at least one failed app install, across {Apps} apps. (data as of {AsOf})
