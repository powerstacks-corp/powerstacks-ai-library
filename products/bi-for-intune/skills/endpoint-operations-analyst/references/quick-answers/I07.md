# I07: Do any devices have a disk that's about to fail?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR Reporting = CALCULATE ( DISTINCTCOUNT ( 'Device Physical Disk'[Intune Device ID] ), TREATAS ( Active, 'Device Physical Disk'[Intune Device ID] ) )
    VAR Smart = CALCULATE ( DISTINCTCOUNT ( 'Device Physical Disk'[Intune Device ID] ), 'Device Physical Disk'[Disk S.M.A.R.T Predict Failure] = TRUE (), TREATAS ( Active, 'Device Physical Disk'[Intune Device ID] ) )
EVALUATE
ROW ( "Failing", FORMAT ( Smart + 0, "#,0" ), "Reporting", FORMAT ( Reporting + 0, "#,0" ), "AsOf", AsOf )
```

**Answer:** {Failing} managed devices have a disk that S.M.A.R.T. predicts will fail, out of {Reporting} devices reporting disk health. (data as of {AsOf})
