# I14: How many devices aren't encrypted?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR Phys = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[Cloud PC Enrolled] <> TRUE () )
    VAR NotEnc = CALCULATE ( DISTINCTCOUNT ( 'Device Encryption'[Intune Device ID] ), 'Device Encryption'[Encryption Status] = "Not Encrypted", TREATAS ( Phys, 'Device Encryption'[Intune Device ID] ) )
    VAR Rep = CALCULATE ( DISTINCTCOUNT ( 'Device Encryption'[Intune Device ID] ), 'Device Encryption'[Encryption Status] IN { "Encrypted", "Not Encrypted" }, TREATAS ( Phys, 'Device Encryption'[Intune Device ID] ) )
EVALUATE
ROW ( "NotEncrypted", FORMAT ( NotEnc + 0, "#,0" ), "Reporting", FORMAT ( Rep + 0, "#,0" ), "Pct", FORMAT ( DIVIDE ( NotEnc + 0, Rep ) + 0, "0.0%" ), "AsOf", AsOf )
```

**Answer:** {NotEncrypted} of {Reporting} managed devices that report encryption status ({Pct}) are not encrypted. Cloud PCs are excluded because they aren't normally encrypted. (data as of {AsOf})
