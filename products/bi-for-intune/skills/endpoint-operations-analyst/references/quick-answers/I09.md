# I09: Which remediation script is failing on the most devices?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR ByPkg =
        SUMMARIZECOLUMNS (
            'Proactive Remediation'[Script Package Name],
            TREATAS ( { "Remediation Failed", "Script Error" }, 'Proactive Remediation State'[Remediation Status] ),
            TREATAS ( Active, 'Proactive Remediation State'[Intune Device ID] ),
            "N", DISTINCTCOUNT ( 'Proactive Remediation State'[Intune Device ID] )
        )
    VAR TopPkg = TOPN ( 1, ByPkg, [N], DESC, 'Proactive Remediation'[Script Package Name], ASC )
    VAR Pkg = MAXX ( TopPkg, 'Proactive Remediation'[Script Package Name] )
    VAR Known =
        CALCULATE ( DISTINCTCOUNT ( 'Proactive Remediation State'[Intune Device ID] ),
            'Proactive Remediation'[Script Package Name] = Pkg,
            'Proactive Remediation State'[Remediation Status] IN { "Success", "Skipped", "Remediation Failed", "Script Error" },
            TREATAS ( Active, 'Proactive Remediation State'[Intune Device ID] ) )
EVALUATE
ROW ( "Script", Pkg, "Devices", FORMAT ( MAXX ( TopPkg, [N] ) + 0, "#,0" ), "Known", FORMAT ( Known + 0, "#,0" ), "Pct", FORMAT ( DIVIDE ( MAXX ( TopPkg, [N] ) + 0, Known ) + 0, "0.0%" ), "AsOf", AsOf )
```

**Answer:** The remediation failing on the most devices is {Script}: {Devices} managed devices (failed or script error), {Pct} of the {Known} with a result for it. (data as of {AsOf})
