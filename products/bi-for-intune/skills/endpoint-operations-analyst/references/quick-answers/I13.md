# I13: How many devices are non-compliant?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR NC = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[Compliance] = "Non Compliant" )
    VAR NC30 = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[Compliance] = "Non Compliant", NOT ISBLANK ( Device[Last Check-In (Days)] ), Device[Last Check-In (Days)] <= 30 )
    VAR Total = COUNTROWS ( Active )
EVALUATE
ROW ( "NonCompliant", FORMAT ( NC + 0, "#,0" ), "Total", FORMAT ( Total + 0, "#,0" ), "Pct", FORMAT ( DIVIDE ( NC + 0, Total ) + 0, "0.0%" ), "Recent", FORMAT ( NC30 + 0, "#,0" ), "AsOf", AsOf )
```

**Answer:** {NonCompliant} of {Total} managed devices ({Pct}) are non-compliant; {Recent} of them checked in within the last 30 days. (data as of {AsOf})
