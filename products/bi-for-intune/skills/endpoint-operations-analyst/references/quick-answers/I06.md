# I06: Which 10 devices checked in longest ago?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR D =
        CALCULATETABLE (
            ADDCOLUMNS ( VALUES ( Device[Intune Device ID] ),
                "Nm", CALCULATE ( MAX ( Device[Device Name] ) ),
                "Dy", CALCULATE ( MIN ( Device[Last Check-In (Days)] ) ) ),
            Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, NOT ISBLANK ( Device[Last Check-In (Days)] ) )
    VAR T = TOPN ( 10, D, [Dy], DESC, [Nm], ASC, Device[Intune Device ID], ASC )
EVALUATE
SELECTCOLUMNS ( T, "Device", [Nm], "Days", FORMAT ( [Dy] + 0, "#,0" ), "AsOf", AsOf, "SortDays", [Dy] )
ORDER BY [SortDays] DESC, [Device] ASC
```

**Answer:** The 10 managed devices with the oldest check-in (data as of {AsOf})

**Each row:** {Device}: {Days} days since last check-in
