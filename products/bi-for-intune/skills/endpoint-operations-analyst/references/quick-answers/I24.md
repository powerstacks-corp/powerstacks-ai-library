# I24: How many devices are corporate versus personal?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR Corp = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[Ownership] = "Corporate" )
    VAR Pers = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[Ownership] = "Personal" )
    VAR Total = COUNTROWS ( Active )
EVALUATE
ROW ( "Corporate", FORMAT ( Corp + 0, "#,0" ), "CorporatePct", FORMAT ( DIVIDE ( Corp + 0, Total ) + 0, "0.0%" ), "Personal", FORMAT ( Pers + 0, "#,0" ), "PersonalPct", FORMAT ( DIVIDE ( Pers + 0, Total ) + 0, "0.0%" ),
    "Other", FORMAT ( Total - Corp - Pers + 0, "#,0" ), "Total", FORMAT ( Total + 0, "#,0" ), "AsOf", AsOf )
```

**Answer:** Of {Total} managed devices, {Corporate} ({CorporatePct}) are corporate-owned and {Personal} ({PersonalPct}) are personal; {Other} have another or unknown ownership. (data as of {AsOf})
