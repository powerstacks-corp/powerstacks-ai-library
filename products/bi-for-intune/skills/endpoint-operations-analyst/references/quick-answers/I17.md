# I17: Which Windows devices aren't in Windows Update for Business reports?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR WinOS = { "Windows 10", "Windows 11", "Windows10" }
    VAR Win = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[OS] IN WinOS )
    VAR NotEn = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[OS] IN WinOS, Device[Update Compliance Enrolled] <> TRUE () )
    VAR Reg = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[OS] IN WinOS, Device[Update Compliance Enrolled] <> TRUE (), Device[Join Type] = "Azure AD registered" )
EVALUATE
ROW ( "NotEnrolled", FORMAT ( NotEn + 0, "#,0" ), "Windows", FORMAT ( Win + 0, "#,0" ), "Pct", FORMAT ( DIVIDE ( NotEn + 0, Win ) + 0, "0.0%" ), "Registered", FORMAT ( Reg + 0, "#,0" ), "AsOf", AsOf )
```

**Answer:** {NotEnrolled} of {Windows} managed Windows 10 and 11 devices ({Pct}) aren't enrolled in Windows Update for Business reports, so they have no update status. {Registered} of them are Microsoft Entra registered, which those reports don't support. (data as of {AsOf})
