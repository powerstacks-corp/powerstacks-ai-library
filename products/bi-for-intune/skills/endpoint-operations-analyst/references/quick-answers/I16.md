# I16: How many devices have out-of-date Microsoft 365 Apps?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR Win = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[OS] IN { "Windows", "Windows 10", "Windows 11", "Windows10" } )
    VAR Outd = CALCULATE ( DISTINCTCOUNT ( 'Device Microsoft 365'[Intune Device ID] ), 'Device Microsoft 365'[M365 Status] = "Outdated", TREATAS ( Win, 'Device Microsoft 365'[Intune Device ID] ) )
    VAR Known = CALCULATE ( DISTINCTCOUNT ( 'Device Microsoft 365'[Intune Device ID] ), 'Device Microsoft 365'[M365 Status] IN { "Outdated", "Up-To-Date" }, TREATAS ( Win, 'Device Microsoft 365'[Intune Device ID] ) )
EVALUATE
ROW ( "Outdated", FORMAT ( Outd + 0, "#,0" ), "Known", FORMAT ( Known + 0, "#,0" ), "Pct", FORMAT ( DIVIDE ( Outd + 0, Known ) + 0, "0.0%" ), "AsOf", AsOf )
```

**Answer:** {Outdated} of {Known} managed Windows devices with a known Microsoft 365 Apps status ({Pct}) are running an out-of-date version. (data as of {AsOf})
