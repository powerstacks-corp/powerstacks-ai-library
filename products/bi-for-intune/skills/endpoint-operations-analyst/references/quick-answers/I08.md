# I08: Which Windows devices are at or near end of service?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = FORMAT ( MAX ( 'Authorization'[Refresh Time] ), "yyyy-mm-dd hh:nn" ) & " UTC"
    VAR Active = CALCULATETABLE ( VALUES ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" } )
    VAR EOS = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[OS] IN { "Windows", "Windows 10", "Windows 11", "Windows10" }, Device[OS Feature Update Status] = "End Of Service" )
    VAR Near = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[OS] IN { "Windows", "Windows 10", "Windows 11", "Windows10" }, Device[OS Feature Update Is Near EOS (6 Months)] = TRUE (), Device[OS Feature Update Status] <> "End Of Service" )
    VAR NextDate = CALCULATE ( MIN ( Device[OS Feature Update EOS Date] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[OS] IN { "Windows", "Windows 10", "Windows 11", "Windows10" }, Device[OS Feature Update EOS Date] >= TODAY () )
    VAR NextN = CALCULATE ( DISTINCTCOUNT ( Device[Intune Device ID] ), Device[Is Managed] = TRUE (), Device[Managed By] IN { "Intune", "Co-Managed" }, Device[OS] IN { "Windows", "Windows 10", "Windows 11", "Windows10" }, Device[OS Feature Update EOS Date] = NextDate )
EVALUATE
ROW ( "EOS", FORMAT ( EOS + 0, "#,0" ), "Near", FORMAT ( Near + 0, "#,0" ),
    "NextDate", IF ( ISBLANK ( NextDate ), "not reported", FORMAT ( NextDate, "yyyy-mm-dd" ) ),
    "NextDevices", FORMAT ( NextN + 0, "#,0" ), "AsOf", AsOf )
```

**Answer:** {EOS} managed Windows devices are on a Windows version already past end of service, and {Near} more reach it within 6 months. The next end-of-service date is {NextDate} ({NextDevices} devices). Source: Windows Update for Business reports. (data as of {AsOf})
