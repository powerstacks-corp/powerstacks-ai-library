# D07: How many devices have had an exploitable vulnerability over 30 days?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = MAX ( 'Authorization'[Refresh Time] )
    VAR Pop =
        CALCULATETABLE (
            VALUES ( Device[Defender Device ID] ),
            Device[Onboarding Status] = "Onboarded",
            NOT ( Device[Is Excluded] = TRUE () )
        )
    VAR V =
        FILTER (
            ADDCOLUMNS (
                FILTER (
                    'Software Vulnerabilities',
                    'Software Vulnerabilities'[Is Active] = TRUE () && RELATED ( Vulnerability[Exploitability Level] ) = "Exploitable"
                ),
                "Dev", RELATED ( 'Software Devices'[Defender Device ID] )
            ),
            [Dev] IN Pop
        )
    VAR Older = FILTER ( V, DATEDIFF ( 'Software Vulnerabilities'[First Seen], AsOf, DAY ) > 30 )
EVALUATE
ROW (
    "DevicesOver30Days", FORMAT ( COUNTROWS ( DISTINCT ( SELECTCOLUMNS ( Older, "d", [Dev] ) ) ) + 0, "#,0" ),
    "DevicesExploitable", FORMAT ( COUNTROWS ( DISTINCT ( SELECTCOLUMNS ( V, "d", [Dev] ) ) ) + 0, "#,0" ),
    "AsOf", FORMAT ( AsOf, "yyyy-mm-dd hh:nn" )
)
```

**Answer:** {DevicesOver30Days} of the {DevicesExploitable} devices with an exploitable vulnerability have had one listed by Defender for more than 30 days (data as of {AsOf})
