# D14: How many devices have not been seen in 7 days?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = MAX ( 'Authorization'[Refresh Time] )
    VAR Pop =
        CALCULATETABLE (
            VALUES ( Device[Defender Device ID] ),
            Device[Onboarding Status] = "Onboarded",
            NOT ( Device[Is Excluded] = TRUE () )
        )
    VAR Ages =
        ADDCOLUMNS (
            FILTER ( Device, Device[Onboarding Status] = "Onboarded" && NOT ( Device[Is Excluded] = TRUE () ) ),
            "Age", DATEDIFF ( Device[Last Seen], AsOf, DAY ) )
EVALUATE
ROW (
    "NotSeen7Days", FORMAT ( COUNTROWS ( FILTER ( Ages, [Age] > 7 ) ) + 0, "#,0" ),
    "NotSeen30Days", FORMAT ( COUNTROWS ( FILTER ( Ages, [Age] > 30 ) ) + 0, "#,0" ),
    "OnboardedDevices", FORMAT ( COUNTROWS ( Ages ) + 0, "#,0" ),
    "AsOf", FORMAT ( AsOf, "yyyy-mm-dd hh:nn" )
)
```

**Answer:** {NotSeen7Days} of {OnboardedDevices} onboarded devices were last seen more than 7 days before collection, {NotSeen30Days} of them more than 30 days (data as of {AsOf})
