# D13: How many onboarded devices have no vulnerability assessment data?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = MAX ( 'Authorization'[Refresh Time] )
    VAR Pop =
        CALCULATETABLE (
            VALUES ( Device[Defender Device ID] ),
            Device[Onboarding Status] = "Onboarded",
            NOT ( Device[Is Excluded] = TRUE () )
        )
    VAR WithSoftware = DISTINCT ( SELECTCOLUMNS ( 'Software Devices', "Id", 'Software Devices'[Defender Device ID] ) )
    VAR NotAssessed = EXCEPT ( Pop, WithSoftware )
    VAR NotSeen30 =
        FILTER ( NotAssessed,
            DATEDIFF ( LOOKUPVALUE ( Device[Last Seen], Device[Defender Device ID], [Defender Device ID] ), AsOf, DAY ) > 30 )
EVALUATE
ROW (
    "NotAssessed", FORMAT ( COUNTROWS ( NotAssessed ) + 0, "#,0" ),
    "OnboardedDevices", FORMAT ( COUNTROWS ( Pop ) + 0, "#,0" ),
    "SharePct", FORMAT ( DIVIDE ( COUNTROWS ( NotAssessed ), COUNTROWS ( Pop ) ) * 100, "0.0" ),
    "NotSeenOver30Days", FORMAT ( COUNTROWS ( NotSeen30 ) + 0, "#,0" ),
    "AsOf", FORMAT ( AsOf, "yyyy-mm-dd hh:nn" )
)
```

**Answer:** {NotAssessed} of {OnboardedDevices} onboarded devices ({SharePct}%) have no assessment data, so their exposure is unknown; {NotSeenOver30Days} of them were last seen more than 30 days before collection (data as of {AsOf})
