# D17: When was the Defender data last collected?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = MAX ( 'Authorization'[Refresh Time] )
EVALUATE
ROW (
    "AsOf", FORMAT ( AsOf, "yyyy-mm-dd hh:nn" ),
    "LatestDeviceLastSeen", FORMAT ( MAX ( Device[Last Seen] ), "yyyy-mm-dd hh:nn" )
)
```

**Answer:** The Defender data was last collected at {AsOf} (the model does not state a time zone); the most recent device check-in in it is {LatestDeviceLastSeen} (data as of {AsOf})
