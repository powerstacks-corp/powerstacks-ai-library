# D15: How many devices are onboarded to Defender?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = MAX ( 'Authorization'[Refresh Time] )
    VAR Pop =
        CALCULATETABLE (
            VALUES ( Device[Defender Device ID] ),
            Device[Onboarding Status] = "Onboarded",
            NOT ( Device[Is Excluded] = TRUE () )
        )
EVALUATE
ROW (
    "Onboarded", FORMAT ( COUNTROWS ( Pop ) + 0, "#,0" ),
    "Excluded", FORMAT ( CALCULATE ( COUNTROWS ( Device ), Device[Is Excluded] = TRUE () ) + 0, "#,0" ),
    "DiscoveredNotOnboarded", FORMAT ( CALCULATE ( COUNTROWS ( Device ), Device[Onboarding Status] = "Can Be Onboarded" ) + 0, "#,0" ),
    "AsOf", FORMAT ( AsOf, "yyyy-mm-dd hh:nn" )
)
```

**Answer:** {Onboarded} devices are onboarded to Defender for Endpoint (not counting {Excluded} excluded); Defender also discovered {DiscoveredNotOnboarded} devices that are not onboarded (data as of {AsOf})
