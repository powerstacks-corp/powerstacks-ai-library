# D01: How many devices have an exploitable vulnerability right now?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = MAX ( 'Authorization'[Refresh Time] )
    VAR Pop =
        CALCULATETABLE (
            VALUES ( Device[Defender Device ID] ),
            Device[Onboarding Status] = "Onboarded",
            NOT ( Device[Is Excluded] = TRUE () )
        )
    VAR Assessed =
        INTERSECT ( Pop, DISTINCT ( SELECTCOLUMNS ( 'Software Devices', "Id", 'Software Devices'[Defender Device ID] ) ) )
    VAR V =
        FILTER (
            ADDCOLUMNS (
                FILTER (
                    'Software Vulnerabilities',
                    'Software Vulnerabilities'[Is Active] = TRUE () && RELATED ( Vulnerability[Exploitability Level] ) = "Exploitable"
                ),
                "Dev", RELATED ( 'Software Devices'[Defender Device ID] )
            ),
            [Dev] IN Pop
        )
    VAR N = COUNTROWS ( DISTINCT ( SELECTCOLUMNS ( V, "d", [Dev] ) ) ) + 0
    VAR A = COUNTROWS ( Assessed ) + 0
EVALUATE
ROW (
    "Devices", FORMAT ( N, "#,0" ),
    "AssessedDevices", FORMAT ( A, "#,0" ),
    "SharePct", FORMAT ( DIVIDE ( N, A ) * 100, "0.0" ),
    "AsOf", FORMAT ( AsOf, "yyyy-mm-dd hh:nn" )
)
```

**Answer:** {Devices} of {AssessedDevices} assessed devices ({SharePct}%) have at least one active vulnerability that Defender rates Exploitable (data as of {AsOf})
