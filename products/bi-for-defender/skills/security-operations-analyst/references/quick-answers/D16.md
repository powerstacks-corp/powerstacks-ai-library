# D16: What OS versions are our onboarded devices running?

Back to [quick answers](../quick-answers.md).

```dax
DEFINE
    VAR AsOf = MAX ( 'Authorization'[Refresh Time] )
    VAR Pop =
        CALCULATETABLE (
            VALUES ( Device[Defender Device ID] ),
            Device[Onboarding Status] = "Onboarded",
            NOT ( Device[Is Excluded] = TRUE () )
        )
    VAR Devs = FILTER ( Device, Device[Onboarding Status] = "Onboarded" && NOT ( Device[Is Excluded] = TRUE () ) )
    VAR ByOs = GROUPBY ( Devs, Device[OS], Device[OS Release ID], "N", SUMX ( CURRENTGROUP (), 1 ) )
    VAR TopRows = TOPN ( 10, ByOs, [N], DESC, Device[OS], ASC, Device[OS Release ID], ASC )
EVALUATE
GENERATEALL (
    ROW ( "AsOf", FORMAT ( AsOf, "yyyy-mm-dd hh:nn" ), "OnboardedDevices", FORMAT ( COUNTROWS ( Devs ) + 0, "#,0" ), "Versions", FORMAT ( COUNTROWS ( ByOs ) + 0, "#,0" ) ),
    SELECTCOLUMNS ( TopRows,
        "Rank", RANKX ( TopRows, [N] ),
        "OS", Device[OS],
        "Release", Device[OS Release ID],
        "Devices", FORMAT ( [N], "#,0" ) )
)
ORDER BY [Rank], [OS], [Release]
```

**Answer:** {OnboardedDevices} onboarded devices run {Versions} OS and release combinations; the most common are below (data as of {AsOf})

**Each row:** {Rank}. {OS} {Release}: {Devices} devices
