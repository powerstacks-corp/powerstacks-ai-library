# Shared Foundation

> Not released. No shared foundation files have been published yet.

This folder will hold guidance that applies to every PowerStacks product, written once and reused by each product package. Examples of what belongs here:

- Output conventions, such as how results and supporting numbers are presented.
- How to separate findings from inference and how to state uncertainty.
- General rules against unsupported assumptions.

Product-specific meaning, such as terminology or how a measure is defined, belongs in the product's own folder under [products](../products/bi-for-intune/README.md), not here.

When a product package is released, the shared files it needs will be listed as dependencies in its [manifest](../manifests/README.md).
