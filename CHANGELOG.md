# Changelog

## 2026-10-24: Quick Questions and Saved Answers

- **Endpoint Operations Analyst** 0.12.0-preview and **Security Operations Analyst** 0.2.0-preview answer short, single questions (for example "How many devices haven't checked in for 30 days?") with one query each, without running the full briefing.
- Answers are saved on your computer and reused for the same question until the semantic model refreshes. When the refresh time changes, saved answers for that model are discarded.
- Every answer states the data refresh time.

## 2026-10-24: Preview

- Added the **Endpoint Operations Analyst** skill for BI for Intune (version 0.11.0-preview).
- Added the **Security Operations Analyst** skill for BI for Defender (version 0.1.0-preview).
- Both skills can produce an executive PowerPoint presentation and a one-page interactive HTML report from a briefing.
